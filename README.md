# Neon Snake

A simple Android snake game built with Kotlin.

## Features
- grid-based snake gameplay
- touch controls
- score tracking
- restart button
- neon-style UI

## Run locally
Open the project in Android Studio and sync Gradle.

## To build
- File > Open > project folder
- wait for Gradle sync
- select a device or emulator
- click Run

## Notes
This is a starter build intended for testing and monetization experiments.
